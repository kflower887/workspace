# 망고월드 (Mango World)

Toca Boca / Game World류의 "장소 탐험 + 자유 놀이" 샌드박스 게임을 한국,
그중에서도 **군포시 당정동** 지역 특성으로 로컬라이즈한 프로토타입입니다.

- 주인공: **김하린** (9세, 여아, 당정초등학교 2학년)
- 배경: 군포시 당정동
- 방문 가능한 10개 장소: 우리집 · 당정초등학교 · 무인카페 · 태권도학원 ·
  놀이터 · 피아노학원 · 음식점 · 문구야놀자 · 마트 · 은행

## 실행 방법

빌드 도구나 설치 과정 없이 정적 파일만으로 동작합니다.

```bash
cd MangoWorld
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속 (모바일 화면비를 권장)
```

`index.html`을 브라우저에서 바로 열어도 대부분 동작하지만, `localStorage`
저장 기능을 정상적으로 쓰려면 위처럼 간단한 로컬 서버로 여는 것을 권장합니다.

## 게임 구조

```
MangoWorld/
├── index.html        # 화면 골격 (상단바 / 지도 화면 / 장소 화면)
├── css/style.css      # 망고 파스텔 톤 UI, 장소별 테마 색상
├── js/data.js          # 장소, 꾸미기 아이템, 메뉴, 캐릭터 커스터마이징 옵션 데이터
├── js/avatar.js         # 김하린 캐릭터 SVG 아바타 렌더러 (머리/옷 색 커스터마이징)
└── js/game.js            # 게임 상태 관리, 화면 전환, 상호작용 로직
```

## 놀이 방식

- **자유 탐험**: 지도에서 9개 장소를 자유롭게 오갈 수 있어요. 정해진 목표나
  실패 조건이 없는 샌드박스 방식입니다.
- **물건 배치**: 각 장소마다 "보관함" 탭에서 소유한 아이템을 선택하고,
  방 화면을 탭하면 원하는 위치에 배치돼요. 배치된 아이템을 다시 탭하면 치워집니다.
- **상점**: "상점" 탭에서 장소별 꾸미기 아이템을 망고코인으로 구매합니다.
  문구야놀자에서 산 학용품은 우리집에 진열할 수 있어요.
- **자유롭게 사먹기**: 무인카페, 음식점, 마트에서는 메뉴를 골라 망고코인으로
  구매하면 바로 먹는 연출이 나와요 (소모성, 배치 없음). 마트에서는 간식 외에도
  휴지·장난감·과일 바구니 같은 생필품을 사서 우리집에 진열할 수도 있어요.
- **미니 활동**
  - 태권도학원: 발차기 연습 → 망고코인 획득, 5회마다 띠 승급 (흰 → 노랑 →
    초록 → 파랑 → 빨강 → 검정)
  - 피아노학원: 건반을 눌러 실제 소리(Web Audio)로 연주 후 연습 완료 시
    망고코인 획득
  - 놀이터: 그네/미끄럼틀/시소를 타며 노는 연출 (자유 놀이, 보상 없음)
  - 은행: 하루 한 번 용돈 받기 + 지갑 ↔ 저금통 저금/출금
  - 우리집: 옷장에서 머리 색 / 옷 색을 바꾸는 꾸미기(드레스업)
- **저장**: 모든 진행 상황(코인, 소유 아이템, 배치 상태, 캐릭터 커스터마이징,
  태권도 띠, 일일 활동 기록)은 브라우저 `localStorage`에 자동 저장됩니다.

## 플레이스토어 출시로 확장하려면

현재는 순수 HTML/CSS/JS 웹 프로토타입입니다. 실제 Play Store 앱으로
패키징하려면 다음과 같은 방향을 고려할 수 있어요.

1. **Capacitor / Cordova**로 웹뷰 기반 APK/AAB 빌드
2. **TWA (Trusted Web Activity)**로 PWA를 그대로 스토어에 등록
3. 이모지 기반 아이콘을 자체 제작 일러스트(고해상도 PNG/SVG)로 교체
4. 배경음악·효과음, 아동용 개인정보처리방침(광고/결제 없는 경우도 필수) 준비
5. Google Play 아동 대상 정책(Families Policy) 및 콘텐츠 등급 심사 대응

이 저장소의 구조(`data.js`에 장소/아이템 정의)는 그대로 유지한 채 그래픽만
교체해도 확장이 쉽도록 설계했습니다.
